# ICU transition analysis

Analysis code for a multicenter clinical research project.

Download and extract `ICU_Culture_Analysis_Code.zip` for the analysis programs, dependencies, and instructions.

## Data access

The source datasets require independent authorization and are subject to their respective data use agreements. Perform analyses in an authorized local environment. Do not upload restricted records, clinical notes, patient-level extracts, or logs containing restricted information to online AI services, public repositories, or other third-party services. Review aggregate outputs before sharing.

See the [PhysioNet guidance](https://physionet.org/news/post/llm-responsible-use/) and the data use agreements for each source.
